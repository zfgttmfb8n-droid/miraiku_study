miraiku 公開用パッケージ
========================

ファイル
- index.html: アプリ本体
- manifest.webmanifest / icon.svg: ホーム画面追加用の設定とアイコン
- sw.js: 静的ファイルのキャッシュ（HTTPSで配信した場合）
- privacy.html: 現バージョンのデータ保存についての説明
- README.txt: この説明

志望校の入力例は「東京大学 理科三類」です。

公開方法（GitHub Pagesの例）
1. GitHubで新しいリポジトリを作成する。
2. このフォルダ内のファイルをリポジトリのルートへアップロードする。
3. リポジトリの Settings > Pages から公開元を設定する。
4. 発行されたURLをスマホで開いて動作確認する。
5. HTTPSのURLをホーム画面に追加すると、対応環境ではアプリのように起動できます。

注意
- この版は静的なフロントエンドです。ログイン、クラウド保存、複数端末同期、決済、サーバー側のバックアップはありません。
- 教材・進捗データはブラウザのローカルストレージに保存されます。重要なデータは定期的にJSON書き出ししてください。
- このアプリの計画は、登録された単位あたり所要時間からの目安です。合格を保証するものではありません。
- 一般公開前に、複数ブラウザ・端末でのテスト、アクセシビリティ、エラー処理、プライバシー説明を確認してください。
- クラウド保存やユーザー登録を追加する場合は、認証・アクセス制御・データ削除機能・運営者連絡先等を設計し直す必要があります。
